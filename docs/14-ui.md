## Look

- Each project designs its own look first, on a Claude Design canvas: screens, tokens, motion moments. The clickable prototype is plain HTML, CSS and JS ([02](02-stack.md)), so its files become `templates/` and `static/`.
- The project's `docs/NN-design.md` links the canvas and holds the tokens (colour light and dark, type, radii) and one row per motion moment: what it tells the user, how, file.
- `cmd/<bin>/static/base.css` holds the look tokens; components use them through `var(--*)`.
- Floor: text contrast ≥ 4.5:1, touch targets ≥ 44 px, inputs ≥ 16 px (iOS zooms into smaller ones).

## Motion

Motion shows what changed: appeared, moved, went where. A celebration marks a rare moment, once. Never decoration.

| Need | Use |
|---|---|
| hover, press, focus | `transition` |
| show / hide: `<dialog>`, `[popover]`, toast, `[hidden]` | `transition` + `@starting-style` + `transition-behavior: allow-discrete` |
| page → page | `@view-transition { navigation: auto; }`, `view-transition-name` on shared elements |
| fragment swap after `fetch` | `document.startViewTransition(swap)` |
| an element grows into a view: photo, composer | [shared element](#shared-element) |
| drag, flick, dismiss | rAF `spring()` from the finger's velocity: [sheet](#sheet-with-page-depth) |
| a bar reacting to scroll | `animation-timeline: scroll()`, a JS class where unsupported: [header](#scroll-driven-header) |
| sequence, values from JS | `element.animate()` |
| in progress, error | `@keyframes`: spinner, skeleton, shake |

- Respond on `pointerdown`: the pressed state shows at touch, the action runs on `click`. iOS shows `:active` only with a `touchstart` listener: one passive no-op on `document`.
- A released gesture keeps the finger's velocity and lands where the flick would carry it, not where the finger let go. `animate()` can't start from a velocity: rAF `spring()`.
- Past an edge: rubber band `(1 − 1/(x/d + 1))·d`, x past the edge, d the limit.
- A new touch stops a running spring where it is.
- Leave the way you came: close reverses open, back to its source.
- Frequent actions (press, toggle, tab, menu) finish within `--dur-4` (420 ms).
- Bounce only for momentum or celebration.
- Reduced motion: no travel, no particles; state snaps or cross-fades. JS helpers check it too.

Don't: GSAP, Motion, anime.js, AOS, jQuery or any animation library · Lottie or video for UI chrome · parallax, scroll-jacking, autoplay loops.

## Springs

`linear()` curves sampled from a damped spring, mass 1. The duration token is its settle time.

| Token | Stiffness / damping | Duration | Overshoot | Use |
|---|---|---|---|---|
| `--ease-snappy` | 420 / 36 | `--dur-4` 420 ms | 0.3 % | press, toggle, tab, menu, counter |
| `--ease-smooth` | 190 / 27.6 | `--dur-5` 670 ms | 0 | sheet, shared element, page morph |
| `--ease-bouncy` | 300 / 16 | `--dur-6` 870 ms | 19.5 % | a like, a new item landing |
| `--ease-wobbly` | 170 / 11 | `--dur-7` 1180 ms | 23 % | celebration |

- A spring travels with its duration: `var(--dur-5) var(--ease-smooth)`.
- A new or retuned spring: `scripts/springs.go` samples the closed-form step response (mass 1) over its settle time (|x − 1| < 0.1 %), simplifies it (Ramer–Douglas–Peucker, 0.002 of travel) and prints the `linear()` curve and the settle time, rounded to 10 ms. Never hand-edit a curve.

## How to apply

- `cmd/<bin>/static/motion.css` holds the tokens, shared `@keyframes` and the reduced-motion rule. Elsewhere only `var(--dur-*)`, `var(--ease-*)`: no literal ms, `cubic-bezier()` or `linear()`. JS reads the same tokens (`getComputedStyle`).
- Enter `--ease-out`, exit `--ease-in`, move on screen `--ease-in-out`; physical motion: a [spring](#springs).
- Animate `transform`, `opacity`, `translate`, `scale`, `rotate`; `filter`, `clip-path`, `border-radius` only on small elements or one layer. Never `width`, `height`, `top`, `left`, `margin`.
- CSP: JS toggles a class or `data-state`; a computed value goes in via `el.style.setProperty('--x', v)`.
- Input never waits: controls work from the first frame; no submit or navigation on `animationend`.
- Loops only while something is in progress.
- Unsupported feature: the same end state, at once (no View Transition: plain update; no scroll timeline: JS class).
- Copied code: only the keyframes used, into `motion.css`, with `/* from <url> · <license> */` above.
- Check: DevTools → Animations at 10% speed; OS "reduce motion" on; gestures and haptics on a real iPhone and Android phone. Playwright: [12](12-tests.md#ui).

```js
// motion.js: a View Transition when supported and allowed, else the plain update
export const reduced = () => matchMedia('(prefers-reduced-motion: reduce)').matches;
export function transition(update) {
  if (!document.startViewTransition || reduced()) return Promise.resolve(update());
  const t = document.startViewTransition(update);
  t.ready.catch(() => {});  // skipped: hidden tab, a newer transition
  return t.finished;
}

// a damped spring per frame, starting at the finger's velocity (units/s); stop() interrupts it
export function spring({ from, to, velocity = 0, stiffness = 300, damping = 30, precision = 0.5, onUpdate, onDone }) {
  if (reduced()) { onUpdate(to); onDone?.(); return { stop() {} }; }
  let x = from, v = velocity, last = performance.now(), raf;
  const tick = now => {
    const dt = Math.min(0.064, (now - last) / 1000), n = Math.ceil(dt / 0.004);  // 4 ms steps
    last = now;
    for (let i = 0; i < n; i++) { v += (-stiffness * (x - to) - damping * v) * dt / n; x += v * dt / n; }
    if (Math.abs(x - to) < precision && Math.abs(v) < precision * 20) { onUpdate(to); onDone?.(); return; }
    onUpdate(x);
    raf = requestAnimationFrame(tick);
  };
  raf = requestAnimationFrame(tick);
  return { stop: () => cancelAnimationFrame(raf) };
}

// rubber band: x past the edge, d the limit
export const rubber = (x, d) => (1 - 1 / (Math.abs(x) / d + 1)) * d * Math.sign(x);
```

## Recipes

### Shared element

```css
.shared { view-transition-name: shared; }
::view-transition-group(shared) { animation-duration: var(--dur-5); animation-timing-function: var(--ease-smooth); }
::view-transition-old(shared) { display: none; }  /* one picture grows, no double image */
::view-transition-new(shared) { animation: none; width: 100%; height: 100%; object-fit: cover; }
```

```js
// the name moves from the source to the target inside the update
from.classList.add('shared');
transition(() => {
  from.classList.remove('shared');
  dialog.showModal();
  to.classList.add('shared');
}).then(() => to.classList.remove('shared'));
```

- One element holds the name at each capture: the source before the update, the target after.
- On `::view-transition-group` set `animation-duration` and `animation-timing-function` only: the `animation` shorthand replaces the browser's keyframes.
- The target first shows pixels already loaded (the source's `currentSrc`); the full size replaces it after.
- Close: the same with `from` and `to` swapped.

### Sheet with page depth

```css
/* JS sets --sheet-y (px) on the panel and --depth (0 closed … 1 open) on .page and the sheet */
.page { transform-origin: 50% 0; scale: calc(1 - var(--depth, 0) * .06); border-radius: calc(var(--depth, 0) * 26px); }
.sheet-panel { translate: 0 var(--sheet-y, 100dvh); }
.sheet::before { opacity: calc(var(--depth, 0) * .32); }  /* the dim; ::backdrop stays transparent */
```

```js
const set = px => {
  y = px;
  panel.style.setProperty('--sheet-y', `${px}px`);
  const depth = Math.max(0, Math.min(1, 1 - px / panel.offsetHeight)).toFixed(3);
  for (const el of [page, sheet]) el.style.setProperty('--depth', depth);
};
// open
sheet.showModal(); set(panel.offsetHeight); anim = spring({ from: y, to: 0, onUpdate: set });
// drag: the grip captures the pointer; pointerdown stops anim first
set(raw < 0 ? rubber(raw, 120) : raw);
v = 0.75 * dy / dt * 1000 + 0.25 * v;  // finger speed in px/s, smoothed
// release: decide from where the flick would carry it
const h = panel.offsetHeight, shut = v > 1100 || y + v * 0.18 > h * 0.42;
anim = spring({ from: y, to: shut ? h : 0, velocity: v, onUpdate: set, onDone: shut ? () => sheet.close() : undefined });
```

- `.page` is viewport-sized (`position: fixed; inset: 0; overflow: hidden`) and its screens scroll inside: a scrolling document would scale about its top. Where the document scrolls (wide layouts): no scale.
- `.sheet` is the `<dialog>`, reset to full-viewport and transparent; the panel sits at its bottom.
- `spring()`, `rubber()`: `motion.js` ([How to apply](#how-to-apply)).

### Scroll-driven header

```css
.topbar::before { opacity: 0; transition: opacity var(--dur-2) var(--ease-out); }  /* the shade */
.scrolled .topbar::before { opacity: 1; }                                          /* JS fallback */
@supports (animation-timeline: scroll()) {
  @media (prefers-reduced-motion: no-preference) {
    /* animation-timeline after the shorthand, which resets it */
    .topbar::before { animation: shade-in linear both; animation-timeline: scroll(nearest); animation-range: 0 40px; }
  }
}
@keyframes shade-in { to { opacity: 1; } }
```

```js
// no scroll timeline, or reduced motion: a class, at most once a frame
if (!CSS.supports('animation-timeline: scroll()') || reduced()) {
  let queued = false;
  scroller.addEventListener('scroll', () => {
    if (queued) return;
    queued = true;
    requestAnimationFrame(() => { queued = false; scroller.classList.toggle('scrolled', scroller.scrollTop > 4); });
  }, { passive: true });
}
```

### Haptics

- A tick confirms a threshold or a commit: pull past the refresh point, a dismiss, a like. Never the only signal.
- Android: `navigator.vibrate(8)` after a user gesture.
- iOS has no Vibration API. Safari ticks when the user toggles a native `<input type="checkbox" switch>`, so toggles use one. Toggling a hidden one from JS worked up to iOS 26.4 and is reported patched in 26.5: verify on a device; never depend on it.
